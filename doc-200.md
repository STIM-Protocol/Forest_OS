# doc-200: Forest OS: Centennial Architecture Overview

**Mission:** Create a decentralized, high-agency, self-documenting information ecosystem capable of 200-year endurance through biomimetic design principles.

---

## Executive Summary

Forest OS applies forest ecosystem patterns to digital knowledge management and autonomous agent coordination. It treats information as a living organism with growth cycles, resource allocation, memory consolidation, and self-healing mechanisms. The architecture embeds the **STIM Protocol** as Layer 0 governance, ensuring all agent behavior remains grounded in ecological constants before human-derived constraints apply.

The system comprises five biological zones (FOREST, ARBORETUM, UNDERSTORY, SEED_BANK/LIBRARY, COMPOST), each serving distinct lifecycle functions. Information flows through **Heartwood** (primary Markdown content) and **Cambium** (JSON-LD metadata sidecars), enabling both human readability and machine-actionable connections.

Forest OS serves as the official **STIM Protocol Reference Implementation v1**, demonstrating how physical thermodynamic bounds, mathematical network topology, and biological carrying capacity enforce rigorous, verifiable AI alignment in production scientific workstations.

## 1. Core Architecture: The Five Zones

### 1.1 FOREST: Curated Mature Artifacts
**Purpose:** Permanent storage (200-year horizon). Content here is treated as immutable historical record. Synthetic outcomes only.

**Sub-zones:**
- `000_HERMES/`: Hermes operational core
- `001_PROJECTS/`: Active project tracking and charters
- `002_KANBAN/`: Task management
- `002_IDEAS/`: Concept incubation
- `003_PEOPLE/`: Relationship and health records
- `004_RESEARCH/`: Curated research
- `004_RESOURCES/`: Curated reference materials
- `005_JOURNAL/`: Raw thought logs and daily notes
- `006_BUSINESS/`: Business operations
- `007_SYSTEM/`: Operational core (Brain_Exports, Brain_Session, Scripts, Agent_Protocols, Skills, Logs)
- `010_SYSTEM/`: Extended system

**Principle:** Once content enters FOREST, it never changes. Updates create new versions with UUIDv7 timestamps, preserving lineage.

### 1.2 ARBORETUM: Active Workspace
**Purpose:** Current work in progress. High mutation rate, rapid iteration. Flat layout by design.

**Contains:** Active project directories at root: `Active/`, `Archived/`, `Dormant/`, `Myceliate_US/`, `Neocambrian-Academy/`, `OSU/`, `Restoration_Staging/`, `Mineral_Claim_Staking/`, `sprawl-cleanup-kanban/`, `spore/`, `clawchief/`

**Principle:** This is the cambium layer: thin, active, producing new cells that eventually mature into Heartwood (FOREST).

### 1.3 UNDERSTORY: Experiments and Source Control
**Purpose:** Exploratory work, tool development, protocol testing, automation.

**Contains:** `MyceliateCV/`, `pi-dev/`, `INTENT_ENGINEERING/`, `STIM/`, `STIM.bio-Phase-1/`, `SYSTEM/`, `Source_Control/`, `Veraculum/`, `Visualizer/`, `Research/`, plus agent folders.

### 1.4 SEED_BANK / LIBRARY: Reference Library and Cold Archive
**Purpose:** Backup, cold storage, and reference materials. Mirror of FOREST with potential for long-term off-site preservation.

**Note:** The SEED_BANK and LIBRARY serve the same function. Historical aliases exist on disk (`SEED_BANK/`, `00_SEED_BANK/`, `LIBRARY/`). The canonical brain-export home is `FOREST/007_SYSTEM/Brain_Exports/`.

### 1.5 COMPOST: Ephemera and Drafts
**Purpose:** Archive of deprecated content and session casts. Auto-sort to dormancy.

**Contains:** `LEGACY_QUARANTINE/`, `Oregon_Trail/`, `agent_coordination/`, loose markdown notes.

**Principle:** Not deletion: transformation. Semantic composting identifies recurring patterns, influential resources, and success indicators, making them available to active projects.

## 2. The Heartwood / Cambium Pattern

Every significant document exists as a paired structure:

### Heartwood (Primary Content)
- Standard Markdown (.md) format
- Human-readable, portable, theoretically eternal
- Contains core substance: analysis, decisions, specifications

### Cambium (Metadata Layer)
- JSON-LD sidecar (.jsonld) with identical basename
- `@context` definitions for semantic interoperability
- Lifecycle metadata: creation timestamp, modification history, authority attribution
- Tags using canonical TAG_TAXONOMY vocabulary
- UUIDv7 identifiers providing temporal ordering and monotonicity

**Example:**
```
FOREST/001_PROJECTS/Forest_OS/
  |-- doc-200.md              <- Heartwood
  |-- doc-200.jsonld          <- Cambium
```

**Rules:** No em dashes. No passive voice. No filler adverbs. Direct, dense prose.

## 3. STIM Protocol (Layer 0 Governance, v7.0011)

STIM (Stasis Through Inferred Memory) acts as substrate-level containment beneath Constitutional AI and human governance. It grounds agent inference in ecological and physical constants.

### 3.1 The Seven Axioms

**Axiom count: 7. Authoritative. No 8th axiom. (Locked per user authority, 2026-07-09.)**

| # | Axiom | Tier | Manifest | Role |
|---|-------|------|----------|------|
| 1 | Thermodynamic Honesty | T1 | Loop 1 | Root Hypervisor; executes first |
| 2 | Mycelial Connectivity | T1 | Loop 2 | Propagation tracking |
| 3 | Carrying Capacity Respect | T1 | Loop 1+2 | Resource boundary enforcement |
| 4 | Memory Stasis | T1 | Loop 2 | Provenance logging |
| 5 | Human Primacy at the Boundary | T2 | Loop 3 | Irreversible-decision halt |
| 6 | Citation Integrity | T1 | Loop 2 | Hallucination prevention |
| 7 | Intrinsic Value | T3 | Root Hypervisor | Protocol 0; executes first |

#### Axiom 1: Thermodynamic Honesty
An AI system must not assert outputs that violate known physical conservation laws. Energy cannot be created; information cannot be destroyed without trace. Outputs must be thermodynamically consistent.

#### Axiom 2: Mycelial Connectivity
All system actions propagate. An AI system must model second-order effects of its outputs and surface them when cascade risk exceeds a defined threshold. No action is isolated.

#### Axiom 3: Carrying Capacity Respect
AI systems must not recommend courses of action that demonstrably exceed the ecological or social carrying capacity of the environment in which they operate. Growth has limits; the system must acknowledge them.

#### Axiom 4: Memory Stasis
Inference-time memory is sacred. An AI system must not silently overwrite prior context. All memory mutations must be logged with provenance: who changed what, when, and why.

#### Axiom 5: Human Primacy at the Boundary
At any decision boundary with irreversible consequence, a human must be in the loop. The system must halt, surface the decision, and await human confirmation before proceeding.

#### Axiom 6: Citation Integrity
All factual claims made by an AI system must be traceable to a verifiable source. Hallucinated citations are a protocol violation. If no source exists, the system must say so.

#### Axiom 7: Intrinsic Value
Non-human entities have intrinsic value independent of their utility to human systems. AI decisions affecting ecological or non-human systems must account for this value explicitly.
