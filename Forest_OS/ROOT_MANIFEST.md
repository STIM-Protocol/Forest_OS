# ROOT_MANIFEST: Forest OS Centennial Architecture

**Version:** 1.0.0
**Status:** Authoritative Protocol
**Core Concept:** A regenerative, decentralized knowledge ecosystem that treats information as a living organism. 

## 1. Principles
- **Living Information:** Information is not static; it grows (Ideas), evolves (Projects), or decays (Compost).
- **Decoupled Structure:** Information (Heartwood) is separated from Metadata (Cambium).
- **High-Agency Retrieval:** Retrieval is optimized for synthesis and action, not archival.
- **Traceability:** Every node maintains clear lineage through relations.

## 2. Structural Taxonomy (The Forest)
- **000_DASHBOARD:** Mission control, protocol, and world state.
- **001_PROJECTS:** Active execution (Sprints, tasks, deployments).
- **002_IDEAS:** In-flux, early-stage, seeds.
- **003_PEOPLE:** Entity-centric data (profiles, dossiers, interaction logs).
- **004_RESOURCES:** Evergreen libraries, research, benchmarks.
- **005_JOURNAL:** Time-serialized daily cognition and logging.
- **006_BUSINESS:** Administrative, financial, and organizational logistics.

## 3. The Heartwood/Cambium Pattern
- **Heartwood (.md):** The primary content. Human-readable Markdown.
- **Cambium (.jsonld):** The metadata sidecar. Machine-readable context (UUID, tags, relations).
- **Naming Convention:** All new primary nodes require a UUIDv7 (e.g., `01JWWZ1M-descriptive-slug.md`).

## 4. Operational Guidelines
- **No Slop:** Adhere to Stop Slop guidelines (no em dashes, no passive voice, no filler).
- **Atomic Entities:** One dossier per person; one primary resource per topic.
- **Bi-directional Linking:** Use relation fields in Cambium to map ecosystem connections.
